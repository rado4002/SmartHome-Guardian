# SmartGuardian Architecture Process

This document summarizes the architecture-first process used across SmartGuardian.

## Process Flow

1. Capture architectural drivers from requirements and constraints.
2. Decompose system into collaborating subsystems.
3. Build architecture views (logical, process, deployment, security).
4. Evaluate technology decisions against quality attributes.
5. Validate architecture consistency with requirements traceability.

## Core Subsystems

- Device Monitoring Subsystem
- Alert Management Subsystem
- Cloud Processing Subsystem
- User Interface Subsystem

## Key Quality Attributes

- Low alert latency
- Security and privacy
- Availability and resilience
- Extensibility for future device types
